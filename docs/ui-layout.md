# 前台布局约定

两个主题各自在 `static/css/layout.css` 定义页面宽度和顶部间距。后端不按主题选择布局，也不提供为特定版式专门设计的数据接口。

| 页面类型 | Cactus | Folio |
|---|---|---|
| 首页、归档、标签、搜索、读者圈、公开主页、个人中心及应用列表 | 外框上限 72rem，边距只由外框提供 | 外框上限 72rem，嵌套容器不再重复加边距 |
| 文章、专栏、普通页面及其评论区 | 与首页、列表使用相同的居中外框及完整内容宽度，不设独立窄阅读列 | 与原线上杂志版一致，上限 58rem（928px），标题、正文和评论区一起居中 |
| 登录、注册、授权表单 | 上限 36rem | 上限 36rem |

这些是最大宽度，手机上自适应剩余空间，不是固定宽度。`scrollbar-gutter: stable` 避免短页面和长页面之间因为滚动条出现而水平跳动。

## 起始位置

- Cactus 站点页由站点导航统一提供下方留白；各页面不重复加顶部 margin/padding。首页自定义内容位于 main 内，内容高度不作限制。文章与普通页面复用 `article_menu.html` 和阅读容器；标题与站点页刊头共用 4rem 顶部留白，不因菜单断点或触摸设备改成 7/8rem。标题字号高于正文二级标题，长标题自然换行且平衡行长。
- Folio 的 main 统一使用 1.5～2rem 的顶部间距，移除正文容器、文章头部的重复 padding。归档、标签和搜索统一为“标题在前、说明在后”，不再混用上方说明和居中标题。
- Folio 阅读页恢复居中衬线标题、紧凑居中作者行、细分隔线和开篇首字下沉。分享仍在作者行，不独占一行；首字下沉仅用于正文的第一个纯文字段落，不作用于标题后的段落、版本/权限提示或带媒体/代码的开篇。
- Folio 桌面目录的位置、可用宽度由 `--reading-width` 推导，与正文留出 2rem 间隔，不另写固定的正文半宽；小于 1440px 时改为与阅读区同宽的折叠目录，给恢复到 928px 的正文留足空间。
- 同一角色的标题长度、管理员配置的自定义内容、用户主动展开菜单可以改变后续内容高度；不通过强制高度、截断正文或验证自定义 HTML 去掩盖差异。
- 平板导航提前折叠，避免登录后的管理入口挤成第二行而改变页面起始高度。

## TOC 与深层讨论

Cactus 保留菜单式 TOC：宽屏（≥1800px）目录位于完整内容区右侧的外部留白中，间隔至少 2rem，不挤窄或偏移正文。常规桌面和平板默认收起，由原有菜单按钮按需展开；菜单内保留上一篇、下一篇、返回顶部和分享，不按桌面宽度隐藏工具行，菜单和目录不增加背景、边框或阴影。手机从底栏“目录”展开。不在正文上方插入另一套吸顶 TOC。保留锚点、当前段落高亮、键盘关闭及焦点返回。Folio 保留其阅读侧栏／折叠 TOC。

三层专栏测试数据为 `deep-book-1 → deep-book-2 → deep-book-3`，每层两篇文章，每篇有游客根评论、会员回复、编辑的第三层回复和管理员的平行回复。数据由浏览器测试写入独立随机 schema，不污染站点数据。

Cactus 菜单工具行在悬停或键盘聚焦时显示纯文字提示：上一篇／下一篇显示目标文章标题，返回顶部／分享显示功能名称。提示位于按钮组左侧，不参与布局、不拦截点击、不增加背景；长标题最多两行，同时保留完整的原生 `title`，屏幕阅读器使用含方向和文章标题的标签。

评论继续采用有界加载：根评论只预览少量直接回复，更深讨论经“查看回复”进入，提供“所有评论／上一级讨论”返回链接。没有改回一次性加载整棵评论树。手机评论缩进收窄，避免越回复可读区域越窄。

## 自动回归

`e2e/theme-contract.spec.ts` 包含：

- `page width and start height contract`：390、768、1024、1440 宽度，检查同类页面的横向位置、宽度、main 起始位置、阅读页标题起点；个人中心和应用列表覆盖会员、编辑、管理员。
- `Cactus original TOC`：320～1920 宽度，检查菜单和手机底栏、锚点、当前章节、Escape、焦点及无横向溢出。
- `Cactus reading pages use the full centered site width`：320～1920 宽度，包含 500/501、1799/1800 边界；检查标题、正文、作者行、评论列表和评论框与站点的完整宽度一致，以及顶部基线、标题层级、长标题和触摸设备的菜单遮挡。
- `three-level books and comment discussions`：两主题、手机和桌面，逐层访问全部六篇文章，进入第三层评论、返回父讨论、实际提交更深回复。
